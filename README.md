## 🛠️ Quick Start Guides

### AWS Deployment
```bash
aws configure
cd terraform/vpc && terraform apply
docker build -t app . && docker push <ECR_URI>/app
```

### Kubernetes
```bash
kubectl create deployment app --image=app:1.0
kubectl expose deployment app --type=LoadBalancer
kubectl scale deployment app --replicas=3
```

### CI/CD with GitHub Actions
Push → Build → Test → Push to ECR → Deploy to ECS
