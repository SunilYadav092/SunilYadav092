# MEARN Full Stack

Study notes and reference material for the **MEARN** stack (MongoDB, Express, Angular/React, Node.js) fundamentals, starting with front-end basics.

## 📁 Folder Structure
```
MEARN Full stack/
├── HTML/
│   └── HTML_Concept.md
├── CSS/
│   └── CSS_Concept.md
├── README.md
└── .gitignore
```

## 📚 Contents
- **HTML/HTML_Concept.md** — Core concepts of HTML: elements, attributes, document structure, semantic tags, forms, and the DOM.
- **CSS/CSS_Concept.md** — Core concepts of CSS: selectors, the cascade, the box model, Flexbox, Grid, and responsive design.
